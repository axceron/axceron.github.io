Privacy policy

Effective date: November 2, 2026.

brok-mailcache is a private, personal tool used only by its owner, Brian Beckman. This policy describes how that tool handles data from Google.

What the tool accesses

The tool requests only the https://www.googleapis.com/auth/gmail.readonly scope. That scope lets it read mail in the owner's own Gmail accounts. It never sends, modifies, or deletes mail.

Where data is stored

Mail and related data are stored only on the owner's own machine, in a local cache that is encrypted at rest. OAuth tokens are encrypted. Nothing leaves that machine as part of normal use.

What the tool does not do

The tool does not sell, share, or transfer data to third parties. No data is used for advertising. No data is used to train AI or machine learning models.

Google API Services User Data Policy

brok-mailcache's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

You can revoke the tool's access to a Google account at https://myaccount.google.com/connections. Revoking access and deleting the local cache removes all data the tool holds for that account.
